# STRIDE transit API

The registry, SQL builders, aggregate queries, cache policy, and OpenAPI contract
are adapted from NoamGaash/stride-lite at revision
`f262d0140c6fc8112c5bd408e663f64207abad10`:
https://github.com/NoamGaash/stride-lite/tree/f262d0140c6fc8112c5bd408e663f64207abad10/api

Copyright and MIT license are retained in LICENSE alongside these modules.
The API uses that revision's external database contract. It does not own or
deploy the database schema. Upstream operational endpoints are not included.
